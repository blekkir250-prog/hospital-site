# 🦷 Сайт Стоматологической Клиники (Hospital Website)

Современный, адаптивный и чистый многостраничный лендинг для стоматологической клиники. Проект содержит информационные блоки о клинике, карточки врачей, прайс-лист на услуги и интерактивную форму для отправки отзывов пациентов с динамической оценкой.

## ✨ Ключевые возможности проекта

* **Интерактивная форма отзывов**: Реализована система оценки качества работы клиники от 1 до 5 звезд. Звезды интерактивно подсвечиваются при наведении и клике. Встроена JavaScript-защита от отправки пустых отзывов (форма не отправится, пока пользователь не выберет оценку).
* **Премиальный темный футер («подвал»)**: Контрастный футер в темных тонах, разделенный на 4 логические колонки (Контакты, Пациентам, О больнице, Документы) для быстрой навигации пациента по официальным данным и лицензиям. Включает заметный блок экстренной связи.
* **Современный UI/UX**: 
  * Фиксированная шапка сайта с трендовым эффектом матового стекла (`backdrop-filter: blur`).
  * Плавный скролл к секциям сайта (`scroll-behavior: smooth`).
  * Эффекты анимации и трансформации при наведении на карточки врачей и услуг.
* **Адаптивная верстка**: Использование CSS Grid и Flexbox позволяет элементам интерфейса корректно перестраиваться под различные разрешения экранов.

## 🛠️ Стек технологий

* **HTML5** — семантическая структура страниц, разделов и элементов управления.
* **CSS3** — стилизация, позиционирование элементов, адаптивные сетки, анимации и кастомное оформление интерфейса в медицинских (голубых и синих) тонах.
* **Vanilla JavaScript** — логика работы интерактивного звездного рейтинга и валидация отправки формы отзывов без использования сторонних библиотек.

## 📁 Структура файлов проекта

* `1text.html` — главная страница сайта (шапка, баннер, блоки врачей, прайс-лист услуг и темный футер).
* `review.html` — страница с формой отправки отзыва пациента.
* `style.css` — файлы стилей, отвечающие за внешний вид и адаптивность элементов на всех устройствах.
* `script.js` — скрипт, управляющий логикой выбора звезд и отправкой формы обратной связи.
